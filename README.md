# B2B-dataset-samples

<h2>各データセットに1,000件以上のレコードを含む、B2Bデータセットのサンプル集です。</h2>

![B2B dataset header](https://github.com/luminati-io/B2B-business-dataset-samples/blob/main/b2b-datasets.PNG)

合計で数千件のレコードを含むビジネスデータセットのサンプルです。すべてのデータセットは <b>Bright Data API</b> を使用して抽出されました。

<h2>データポイントの一部には以下が含まれます：</h2>

* ```url``` : 企業プロフィールへのリンク  
* ```id``` : データセット内における企業の一意識別子  
* ```name``` : 企業の正式名称  
* ```description``` : 企業の沿革、サービス、または製品の簡単な概要  
* ```revenue``` : 企業の総収益  
* ```revenue_currency``` : 収益数値に使用される通貨  
* ```stock_symbol``` : 企業の株式ティッカーシンボル  
* ```website``` : 企業の公式Webサイト  
* ```employees``` : 企業で働く従業員数  
* ```industry``` : 企業が事業を行う主要な業界  
* ```headquarters``` : 企業本社の所在地住所  
* ```phone_number``` : 企業の主要連絡先電話番号  
* ```total_funding_amount``` : 企業が受けた資金調達の総額  
* ```most_recent_funding_amount``` : 直近の資金調達ラウンドで調達した金額  
* ```funding_currency``` : 資金調達額の通貨  
* ```funding_rounds``` : 企業が参加した資金調達ラウンド数  
* ```leadership``` : 主要エグゼクティブと役職の一覧  
* ```popular_searches``` : 企業に関連する一般的な検索語句  
* ```business_classification_codes``` : SIC Code、NAICS Code、Ticker などの Business Classification Codes  
* ```ceo``` : 企業のCEOの氏名および役職  
* ```total_employees``` : 企業の従業員総数  
* ```c_level_employees``` : 企業のCレベル（経営層）エグゼクティブ数  
* ```vp_level_employees``` : 企業のVP（副社長）数  
* ```director_level_employees``` : 企業のDirector（ディレクター）数  
* ```manager_level_employees``` : 企業のManager（マネージャー）数  
* ```non_manager_employees``` : 管理職未満の従業員数  
* ```top_contacts``` : 企業における主要な連絡先人物  
* ```org_chart``` : 企業の組織階層  
* ```social_media``` : 企業の公式ソーシャルメディアプロフィール  
* ```ceo_rating``` : CEOのパフォーマンス評価  
* ```enps_score``` : 従業員満足度を示す Employee Net Promoter Score  
* ```similar_companies``` : プロフィール対象企業と類似する企業  
* ```email_formats``` : 企業で一般的に使用されるメールアドレス形式  
* ```products_owned``` : 企業が提供する製品  
* ```tech_stack``` : 企業が使用しているテクノロジー  
* ```recent_scoops``` : 最近の更新情報、求人、または注目すべき企業の変化  
* ```news_and_media``` : 企業に関連するニュース記事およびメディア掲載  

他にも多数あります。

<h2>B2Bデータセットのユースケースとは何ですか？</h2>

<h3>1. 競合マッピング</h3>
主要企業、プロフェッショナル、従業員の異動を特定することで、競合分析を強化します。競合環境を把握し、企業およびキャリアの動向を追跡し、変化する市場トレンドを評価できます。

<h3>2. 投資データ</h3>
データドリブンな意思決定のために、企業成長と業界の変化を包括的に把握できます。投資戦略を強化し、高い価値を持つ機会を発掘したいヘッジファンド、VC、金融機関に最適です。

<h3>3. セールス＆マーケティング</h3>
詳細な企業プロフィールとレコードにより、リード獲得の取り組みを強化します。理想的な顧客プロファイルを策定し、ターゲットとなるリードリストやカスタムオーディエンスをキュレーションすることで、セールスファネルを最適化できます。
