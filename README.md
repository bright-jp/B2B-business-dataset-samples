# B2B-dataset-samples

<h2>それぞれ1,000件を超えるレコードを含む、B2Bデータセットのサンプル集です。</h2>

![B2B dataset header](https://github.com/bright-jp/B2B-business-dataset-samples/blob/main/b2b-datasets.PNG)

合計で数千件のレコードを含むビジネスデータセットのサンプルです。すべてのデータセットは <b>Bright Data API</b> を使用して抽出されました。

<h2>データポイントの一部は以下のとおりです:</h2>

* ```url``` : 企業のプロフィールリンク  
* ```id``` : データセット内における企業の一意識別子  
* ```name``` : 企業の正式名称  
* ```description``` : 企業の沿革、サービス、または製品の概要  
* ```revenue``` : 企業の総収益  
* ```revenue_currency``` : 収益額に使用される通貨  
* ```stock_symbol``` : 企業の株式ティッカーシンボル  
* ```website``` : 企業の公式Webサイト  
* ```employees``` : 企業で働く従業員数  
* ```industry``` : 企業が主に事業を展開している業界  
* ```headquarters``` : 企業本社の所在地住所  
* ```phone_number``` : 企業の主な連絡先電話番号  
* ```total_funding_amount``` : 企業がこれまでに受けた資金調達総額  
* ```most_recent_funding_amount``` : 直近の資金調達ラウンドで調達した金額  
* ```funding_currency``` : 資金調達額の通貨  
* ```funding_rounds``` : 企業が参加した資金調達ラウンド数  
* ```leadership``` : 主要役員とその役職の一覧  
* ```popular_searches``` : 企業に関連する一般的な用語  
* ```business_classification_codes``` : SIC Code、NAICS Code、Ticker などの事業分類コード  
* ```ceo``` : 企業のCEOの氏名と役職  
* ```total_employees``` : 企業の総従業員数  
* ```c_level_employees``` : 企業内のC-level executivesの人数  
* ```vp_level_employees``` : 企業内のvice presidentsの人数  
* ```director_level_employees``` : 企業内のdirectorsの人数  
* ```manager_level_employees``` : 企業内のmanagersの人数  
* ```non_manager_employees``` : 管理職未満の従業員数  
* ```top_contacts``` : 企業の主要な連絡先担当者  
* ```org_chart``` : 企業の組織階層  
* ```social_media``` : 企業の公式ソーシャルメディアプロフィール  
* ```ceo_rating``` : CEOの業績評価  
* ```enps_score``` : 従業員満足度を示すEmployee Net Promoter Score  
* ```similar_companies``` : 紹介されている企業に類似する企業  
* ```email_formats``` : 企業で一般的に使用されるメールアドレス形式  
* ```products_owned``` : 企業が提供する製品  
* ```tech_stack``` : 企業が使用しているテクノロジー  
* ```recent_scoops``` : 最近の更新情報、求人情報、または注目すべき企業の変化  
* ```news_and_media``` : 企業に関連するニュース記事およびメディア掲載  

その他にも多数あります。

<h2>B2Bデータセットのユースケースとは？</h2>

<h3>1. 競合マッピング</h3>
主要企業、プロフェッショナル、人材の移動を特定することで、競合分析を強化します。競合環境を理解し、企業やキャリアの動向を追跡し、変化する市場トレンドを評価できます。

<h3>2. 投資データ</h3>
データに基づく意思決定のために、企業成長と業界変化の包括的なビューを取得できます。投資戦略を強化し、高価値の機会を発見したいヘッジファンド、VC、金融機関に最適です。

<h3>3. 営業・マーケティング</h3>
詳細な企業プロフィールとレコードにより、リードジェネレーションの取り組みを強化します。ターゲットを絞ったリードリストやカスタムオーディエンスを作成することで、理想的な顧客プロファイルを構築し、営業ファネルを洗練できます。
